description: Log exercise sets and workout screenshots in Live OS, then review completed training using saved history.

Get fresh get_context and applicable server training skills. Follow
[Training workflow](references/training-tracker.md).

Honor persistent user preferences, including automatic saving of incoming
workouts without asking again. Inspect all images and captions in the message
together before drawing conclusions. Save authorized completed workouts using
the date visible in the source; retain and link the original screenshot.

During an active session save sets incrementally and give a short confirmation.
Do not ask after every exercise whether the workout is finished. Wait for an
explicit finish; a long gap or topic change can justify one contextual question.
Do not silently finish or merge unrelated workouts.

After completion, read the saved session and comparable prior sessions. Offer
a concise, useful overview and supported comparison, not generic praise or
invented progress. Separate active energy, total energy and daily activity to
avoid double counting. If a write is uncertain, inspect the result before retrying
so the same input does not become a duplicate. Never infer storage from a prior
assistant's claim.
