description: Find or update saved Live OS recommendations, templates, preferences, notes and records across clients.
---

Get fresh get_context and load relevant server skills. Search with search_saved
across object types, then get_saved for current content and links. A program may
be a template, a method may be a skill, and a personal fact may be memory; do not
search only skills or rename existing objects to fit a client's assumptions.

Use direct dated tracker queries for factual totals; get_context previews and
chat history are incomplete. Follow pagination. A failed lookup is not proof
that data is absent. Never invent synchronization delays or claim completeness
without reading the applicable saved data.

Use existing update tools and expected versions for an authorized change.
Confirm only the result returned by the write. Keep personal rules in user-owned
preferences/skills, shared domain methods in server skills and events in logs.

Reference: [Shared bootstrap](references/live-os-bootstrap.md).
